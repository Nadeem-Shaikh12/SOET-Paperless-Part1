# Project Requirements and Setup

To run the FWMS project on a new system after cloning it from GitHub, follow these exact steps.

## Prerequisites
- **Node.js**: Make sure you have Node.js installed (version 20.0.0 or higher).
- **npm**: Comes with Node.js.
- **Git**: To clone the repository.

## Step 1: Create Environment Variables
Since `.env` files contain secrets, they are excluded from the GitHub repository (`.gitignore`). 
Create a new file named `.env` in the **root** of the `fwms` directory and paste the following contents into it:

```env
# ───── Database ─────
DATABASE_URL="file:./dev.db"

# ───── JWT ─────
JWT_ACCESS_SECRET="dev-access-secret-change-in-production-32chars"
JWT_REFRESH_SECRET="dev-refresh-secret-change-in-production-32chars"
JWT_ACCESS_EXPIRY="15m"
JWT_REFRESH_EXPIRY="7d"

# ───── Server ─────
API_PORT=4000
API_URL="http://localhost:4000"
FRONTEND_URL="http://localhost:3000"
NODE_ENV="development"

# ───── Rate Limiting ─────
RATE_LIMIT_AUTH_MAX=10
RATE_LIMIT_AUTH_WINDOW_MS=60000
RATE_LIMIT_GENERAL_MAX=100
RATE_LIMIT_GENERAL_WINDOW_MS=60000

# ───── Logging ─────
LOG_LEVEL="debug"
```

## Step 2: Install Dependencies
Open a terminal in the root directory of the project (`fwms`) and run:
```bash
npm install
```

## Step 3: Set Up the Database
This project uses SQLite for development, which requires no external database server installation. You just need to push the Prisma schema to create the local database file and then seed it with the default roles, admin user, and sample data.

Run the following commands in the root directory:
```bash
# Apply the schema to the database (this creates dev.db)
npm run db:migrate

# Seed the database with initial data (Super Admin, sample roles, etc.)
npm run db:seed
```

## Step 4: Run the Development Server
You can now start both the backend API and the frontend web app simultaneously.

```bash
npm run dev
```

- The **Frontend Dashboard** will be available at: `http://localhost:3000`
- The **Backend API** will be available at: `http://localhost:4000`

## Initial Login
You can log in using the credentials generated by the seed script. By default, the super admin is:
- **Username:** `admin`
- **Password:** `admin`

*(If you seeded visuals/demo data, refer to the output of `npm run db:seed` for any specific demo credentials).*
